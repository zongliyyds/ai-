# 本地服务运维：bat 端口检测与不秒退

## 核心观点

**双击 bat 秒退的常见根因是端口被后台服务占用**（uvicorn/Flask 等报 "address already in use" 后窗口立即关闭，用户看不到任何报错）。bat 类启动工具必须做三件事：端口检测、启动成功自动开浏览器、失败不秒退。

## 标准模板（Windows）

```bat
@echo off
cd /d D:\RAG

netstat -ano | findstr /r ":8000 .*LISTENING" >nul 2>&1
if %errorlevel%==0 goto :running

start "" cmd /c "ping -n 4 127.0.0.1 >nul & start http://127.0.0.1:8000"
D:\python\python.exe -m uvicorn vaultmind.api.main:app --host 127.0.0.1 --port 8000
if %errorlevel% neq 0 (
    echo [App] start FAILED, exit code %errorlevel%.
    echo Common fixes: ...
    ping -n 9 127.0.0.1 >nul
)
exit /b 0

:running
echo [App] server is ALREADY running on port 8000.
echo Open your browser: http://127.0.0.1:8000
ping -n 6 127.0.0.1 >nul
exit /b 0
```

## 关键细节

- 延时用 `ping -n N 127.0.0.1 >nul` 而不是 `timeout /t`——`timeout` 在 stdin 被重定向的环境会报 "Input redirection is not supported"。
- 探活：`curl.exe -s http://127.0.0.1:8000/health`；Ollama：`curl.exe -s http://127.0.0.1:11434/api/tags`（curl exit 7 = 服务掉了）。
- Ollama serve 是前台阻塞进程，会话/重启后会掉线，属正常，重启即可。

## 适用场景

- 任何"双击即用"的本地演示工具（RAG 演示、数据分析小服务、给同学/老师演示的项目）。
