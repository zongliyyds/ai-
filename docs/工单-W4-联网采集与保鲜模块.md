# 工单 W4-01：联网采集与保鲜模块（设计定稿 · 未开工）

> 节点：W4 追加模块 ｜ 状态：**设计定稿**（2026-09 用户确认，见下文定位）｜ 排期：W4，主线 M3→M7 优先，本模块不阻塞主线
> 依赖：M3/M4 完成后开工；开工前先跑 S1 可行性探测。

## 0. 定位（用户拍板，勿再议）

- **VaultMind 不是搜索引擎**，是"AI 的知识库兼知识沉淀"：检索服务的是**人找相关知识**，不是主力搜索。
- 联网是**补给管线**：帮 AI 采集资料（B）、帮知识保鲜（C）。目的是让 AI 更好完成任务、提高工作效率。
- 因此：**B（主动收集→草稿区→用户审阅入库）为主，C（定期对比库内 vs 网上最新→更新提醒报告）为辅**；**不做 A（临时联网问答）为主**。

## 1. 两大模式

### 模式 B · 主动采集（主力）

```
用户给主题（或 URL 清单）
  → Bing 搜索 / 直抓网页 → 正文清洗（去导航/广告/脚本）
  → 与库内已有笔记做相似度比对（TF-IDF + 同分类约束），标注"可能重复"
  → 生成带 frontmatter 的草稿笔记（来源 URL、抓取时间、原始标题、要点摘要）
  → 落 D:\RAG\data\web_capture\（派生区，绝不写 Vault）
  → 用户审阅：改/删/合并 → 手动复制进 Obsidian → 重跑 python -m vaultmind.ingest 增量索引
```

人机分工：**AI 全程备料，用户掌勺**——效率提升在"找资料 + 整理初稿"两步，入库判断权始终在人。

### 模式 C · 保鲜巡检（辅助）

```
用户维护"保鲜清单"（需要保鲜的笔记/主题列表，默认在 D:\RAG\config\freshness.txt）
  → 手动触发或计划任务：逐条取笔记要点 → Bing 搜最新结果 → 规则式对比
  → 生成 reports\freshness_YYYYMMDD.md（"XXX 笔记可能过时：网上说法已变为…"）
  → 用户决定是否更新笔记（更新仍走 Obsidian 手动）
```

## 2. 数据流与红线（不可破坏）

1. **抓取内容只允许落** `D:\RAG\data\web_capture\` 或 `D:\RAG\reports\`；**绝不自动写入 Vault**（立项书红线）。入库只能由用户手动完成。
2. 联网查询词外发前 **PII 脱敏**（手机号/邮箱/姓名掩码）；默认不携带 Vault 原文全文外发，仅发送查询词/要点摘要。
3. Bing 是当前唯一免费可行路由（2026-09 实测：Bing 200/~98KB/1.2s；百度 1.4KB 反爬页；DDG/Google/SearXNG 均超时）。**限速 ≥1s/请求 + 指数退避**，防反爬。
4. 相似度比对**不用 LLM 判重**，用 TF-IDF 规则（复用 D:\English study 经验：加同分类约束防误判）。
5. 模块失败不影响主线：抓取失败保留原始 HTML 于 web_capture\_raw\ 供人工查看，管道继续。

## 3. 子步骤与产出

| # | 内容 | 产出 |
|---|---|---|
| S1 | Bing HTML 解析可行性探测（title/link/snippet 提取率、反爬反应、限速安全值） | `reports/bing_probe.md` |
| S2 | 采集器：httpx 抓取 + 正文清洗（去脚本/样式/导航，保留标题与正文段落） | `vaultmind/web/capture.py` |
| S3 | 草稿生成：frontmatter 模板 + TF-IDF 相似度比对 + "可能重复"标注 | `vaultmind/web/draft.py` |
| S4 | 保鲜对比：要点抽取（规则式）vs 最新结果 → 更新提醒报告 | `vaultmind/web/freshness.py` |
| S5 | 触发入口：CLI（`python -m vaultmind.web collect <主题>` / `freshness`）+ 可选计划任务 | `vaultmind/web/__main__.py` |

## 4. 验收标准（写之前就知道"什么叫做完"）

1. **红线探针**：跑完整条管道后，Vault 文件清单（154 篇基线）零变化断言通过（pytest 探针）。
2. B：给定一个主题 → `web_capture\` 出现 ≥3 篇草稿，每篇含来源 URL/抓取时间/要点摘要；无网络时管道优雅降级不崩溃。
3. C：给定 5 条保鲜清单 → `reports\freshness_*.md` 生成，每条含"可能过时/未见变化/无法对比"三态判定。
4. 限速合规：请求间隔 ≥1s（日志可查），Bing 429/验证码出现时自动退避并提示。
5. 复用性：S1 探测报告把"免费可用路由 + 限速安全值"沉淀为可复现结论。

## 5. 风险预案

| 风险 | 预案 |
|---|---|
| Bing 反爬升级（验证码/封 IP） | 限速 + 退避 + 降级提示；备选：付费搜索 API（Tavily 等）或自建 SearXNG，均不阻塞主线 |
| 清洗后正文质量差 | 保留原始 HTML 供人工对照；草稿标注"低置信" |
| 相似度比对误判 | 同分类约束 + 阈值保守（宁多标"可能重复"，不自动删） |
| 保鲜对比误报 | 三态判定 + 附原文 vs 最新结果对照链接，人做最终判断 |
