## 1. 交付物

| # | 子步骤 | 产出 |
|---|---|---|
| S1 | retrieval 骨架 | `vaultmind/retrieval/{__init__,bm25,vector,fusion}.py` |
| S2 | BM25 检索 | 查询 jieba 分词 → FTS5 MATCH → bm25 得分 → top-k（空结果兜底） |
| S3 | 向量索引 | bge-m3 批量 embed 全部 chunks（断点续跑）→ `data/embeddings.npy`（float32 N×1024）+ `data/chunk_ids.json` 行映射 |
| S4 | 向量检索 | 查询 embed → numpy 暴力 cosine → top-k |
| S5 | RRF 融合 | 两路各取 top-60 → RRF(k=60) 重排 → 最终 top-k（保留 chunk/文档/章节/得分） |
| S6 | 统一接口 + CLI | `search()` + `D:\python\python.exe -m vaultmind.search "问题" --top 5 --mode bm25\|vector\|hybrid` |
| S7 | 测试与自检 | `tests/test_retrieval.py` + 10 问自查表（见 §3） |
