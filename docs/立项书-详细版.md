## 三、三条护城河（决定简历含金量）

### 护城河 1：结构感知分块（Structure-aware Chunking）
不要 512 token 硬切。你的笔记天然带结构：

```
frontmatter(type/status/tags/source) → H1 标题 → H2 小节 → 段落
```

**策略**：以 H2 为基本 chunk 单元（922 个），超过 ~600 字的再按 H3/段落二次切分；每个 chunk 的正文**前置注入上下文前缀**：

```
[文档: SQLite FTS5 全文搜索配置 | 章节: 分词器配置 | 标签: 编程/数据库, NLP]
↓ 正文
```

面试可讲：为什么不用固定长度切？为什么前缀能提升召回？（答案：短 chunk 语义稀释 + 指代词"它/这个方法"在无上下文时不可检索。）

### 护城河 2：双链知识图谱增强（GraphRAG-lite）
你的 vault 有 **409 条双链**，天然是一张图。解析成边表后：
- 检索命中文档 → 自动带上 **1-hop 邻居**的标题+摘要进入上下文；
- 查询里出现某个概念名 → 图谱扩展把它映射到对应笔记，解决"问法 ≠ 笔记用词"的召回失败。

这比"接一个向量库"高级一档，且**完全是你自己的数据特性**，别人抄不走。

### 护城河 3：可复现评测闭环 + 消融实验
自建 gold 集 → 跑 6 组配置 → 出一张对比表。这是全项目**最值钱的产物**，也是唯一能让面试官相信"你真的懂 RAG 而不只是会调包"的证据。

### 附加护城河 4：数据治理体检报告
同一套管道顺手产出：孤儿笔记、死链、元数据缺失、重复内容、状态值不统一 → **修复建议 + 修复前后对比**。RAG 项目反哺知识库质量，形成闭环叙事。

## 五、技术选型（含"刻意不用什么"）

| 层 | 选型 | 理由 / 面试话术 |
|---|---|---|
| 语言/后端 | Python 3.13 + FastAPI（已装） | 复用 CET-4 项目骨架，零学习成本 |
| 存储 | SQLite（+ FTS5） | 单文件、免部署、可演示；FTS5 你已有实战经验 |
| 向量检索 | **numpy 暴力 cosine**（1000×1024 全量比对 ≈ 毫秒级） | 数据量根本不需要向量库；"先算清规模再选型"本身就是加分项 |
| 可选对比 | `sqlite-vec` 或 Chroma 做一次"暴力 vs HNSW"召回/延迟对比 | 变成第 7 组实验，不为主链路增加依赖 |
| Embedding | **Provider 抽象**：本地 Ollama `bge-m3` / `nomic-embed-text` 优先，云端 DashScope `text-embedding-v3` 兜底 | 复用你 Godot 项目的"三层降级"经验，技术叙事连贯 |
| LLM | 本地 `qwen2.5:7b-instruct`（建议拉取）→ 云端 DeepSeek/Qwen 兜底 | 隐私优先；本地慢就云端，接口一致 |
| 重排 | 一阶段用 **LLM 重排**（零新依赖），后期可选 `bge-reranker-base` 做对照 | 避免一上来就装 torch（2GB+） |
| 前端 | 原生 HTML+CSS+JS + Chart.js | 复用你 CET-4 的"零构建"经验，省时间给评测 |
| 评测 | **自建脚本**（numpy 算指标） | 不引入 ragas，指标公式自己写才讲得清 |
| 版本控制 | git + GitHub（走 gh-proxy.com 镜像） | 你目前**没有 GitHub 作品集**，这是必须补的一块 |

**刻意不用**：LangChain / LlamaIndex（黑盒太多，面试被追问"框架内部怎么做的"会露怯）。手写 300 行 > 调 3000 行魔法。

## 六、里程碑工单（M0–M7）

> 工单格式沿用你自己 Vault 里的《AI 工作流四步法》：**需求 → 实现方案 → 红线 → 验收标准**。每张工单验收通过才进下一环。

### M0 立项与上下文打底（0.5 天）
- **交付物**：项目目录 `D:\deeseek工作区\vaultmind\`、`README.md`（含架构图）、`PLAN.md`（本规划落库）、`CHANGELOG.md`、`requirements.txt`、git 初始化
- **验收**：只看 README + PLAN，一个陌生 AI/人就能知道要做什么、做到什么算完成
- **红线**：不写任何 vault 内容进仓库（只存路径与统计）

### M1 数据管道 + 知识库体检（1.5 天）
- **交付物**：
  - `ingest.py`：扫描 → frontmatter 解析 → 双链抽取 → 清洗（去空文件/模板/临时笔记）→ 结构感知分块 → 写入 `docs/chunks/links`
  - `audit_report.md`：笔记数、chunk 数、图谱边数、孤儿、死链、元数据缺失、重复候选、类型分布
- **验收**：`python -m vaultmind.ingest` 一条命令重建索引；报告中的数字与我实测的基线一致（154 篇 / 922 个 H2 / 409 条双链）
- **红线**：**只读 vault，绝不修改/移动/重命名任何原文件**

### M2 检索层 v1（2 天）
- **交付物**：BM25/FTS5 检索 + 向量检索（Ollama embedding）+ RRF 融合 + `search()` 统一接口 + CLI 调试工具
- **验收**：随便问 10 个"我知道答案在库里"的问题，Top-5 能命中正确笔记 ≥ 8 个
- **风险**：本地 embedding 首次需 `ollama pull bge-m3`（约 1.2 GB）→ 网络可达，你手动执行一次即可

### M3 评测集 + baseline 指标（2 天）★ 最关键
- **交付物**：
  - `eval/gold_set.jsonl`：**60 条 (问题, 标准答案要点, 正确文档/章节)**；流程 = 脚本按笔记生成候选问题 → **你人工筛选/改写**（人机协同标注，可写进简历）
  - `eval/metrics.py`：Recall@1/5/10、MRR、nDCG@10、平均延迟
  - `reports/baseline.md`：第一份真实指标
- **验收**：一条命令 `python -m vaultmind.eval` 输出指标表，重跑结果一致（可复现）
- **红线**：**gold 集禁止由 LLM 直接定稿**，必须人工过一遍——否则评测自我循环，面试一问就穿

### M4 RAG 生成链路（2 天）
- **交付物**：查询改写（图谱扩展）→ 上下文组装（带 `[S#]` 编号 + 来源路径）→ LLM 生成 → **引用校验**（回答里的 `[S#]` 必须真实存在）→ **超纲拒答**

- **红线**：答案不得出现库外事实；宁拒答不编造

### M5 产品层（2.5 天）

- **红线**：UI 美化投入 ≤ 半天（时间要留给评测）

## 七、评测方案（细节，决定可信度）

**检索指标**：Recall@5（主）、Recall@10、MRR、nDCG@10
**生成指标**：引用命中率、引用支持率（引用的 chunk 是否真的支撑该句）、拒答准确率、平均/P95 延迟
**目标值（先测 baseline 再定，切勿先编数字）**：
- Recall@5 ≥ 0.80，MRR ≥ 0.65，nDCG@10 ≥ 0.70
- 引用命中率 ≥ 0.95，拒答准确率 ≥ 0.85，P95 延迟 < 8 s（本地 7B）

**数据分析侧（AI+DA 的关键拼图）**：问答日志落 `qa_logs` 表 → Pandas 归因 → badcase 四分类（检索漏召 / 上下文缺失 / 生成幻觉 / 问题超纲）→ 看板 → 针对性优化 → 对比迭代前后 badcase 率。**这条闭环让你同时能投"数据分析"岗**。

## 八、红线与风险（必须先说清）

1. **隐私第一**：vault 里有你的简历项目（含手机号/邮箱）。方案：① 默认**排除** `10-Projects/wang-*` 与 `60-References` 中的个人信息行；② 加正则 PII 脱敏（手机号/邮箱/身份证）；③ 本地模型优先，云端调用前二次扫描。**面试时主动讲 PII 处理 = 加分项**。
2. **只读 vault**：所有产物写在 `D:\deeseek工作区\vaultmind\`。不改、不移、不重命名你的知识库文件（遵守你自己 Vault 的《AI-Knowledge-Base-Rules》）。
3. **不开源 vault，只开源代码**：如果要开源知识库内容，先跑一次 PII 扫描；更稳的做法是仓库里放 3~5 篇脱敏样例数据 + 生成脚本，让别人能复现你的管道而不泄露你的笔记。
4. **不做"调包侠"**：不引入 LangChain 黑盒；评测指标自己写。
5. **不做无评测的 Demo**：没有指标表的 RAG 项目，在面试官眼里等于 0。
6. **诚实底线**：简历只写实际做出的东西，未完成的模块不写（这条直接复用你 Vault 里的《简历诚实改写与可迁移能力提炼法》）。
7. **沙箱限制**：当前文件策略下我只能写 `D:\deeseek工作区`；操作 Ollama、pip 安装等需要在正常终端执行，或你授权放宽。
