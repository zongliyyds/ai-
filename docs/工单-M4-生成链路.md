> 节点：M4 生成链路（W2 第二块）｜ 前序：M1/M2/M3 已完成（检索三模式可用，gold 60 条 + 正式基线达标）
> 状态：**已完成**（2026-09-16：pytest 32/32 + 在线冒烟 4/4，详见 §5 结果记录）

## 0. 范围界定（防止与 M6 消融撞车）

- **M4 只做生成链路**：检索命中 → 上下文组装（[S#] 编号）→ 本地模型生成 → 引用校验 → 超纲拒答。
- **查询改写/重排/权重调参一律不进 M4**——它们会改变检索行为、破坏 M3 基线的可复现性，归 M6 消融实验（坏例账本已列好靶子）。

## 1. 子步骤与交付物

| # | 内容 | 交付物 |
|---|---|---|
| S1 | 上下文组装：top-k 命中 → 每文档≤2 chunk → 总预算 6000 字符 → `[S#] 文档/章节/正文` 编号块 | `vaultmind/llm/context.py` |
| S2 | 生成器：Ollama `/api/chat`（qwen2.5:7b-instruct，本地默认，无云端调用） | `vaultmind/llm/generator.py` |
| S3 | 引用校验 + 拒答判定（纯函数，不依赖模型）：编号合法性、拒答话术识别 | `vaultmind/llm/validator.py` |
| S4 | 问答 CLI：检索→组装→生成→校验一条命令，支持 `--context-only` 与 `--json` | `vaultmind/ask.py` |
| S5 | 离线探针 + 在线冒烟 | `tests/test_generation.py`、`scripts/m4_smoke.py` |

## 2. 验收标准（写之前就知道"什么叫做完"）

1. **离线探针全绿**：上下文编号连续且每文档≤2、字符预算截断正确；引用提取/合法性判定/拒答话术识别精确断言（pytest 全量通过，含既有 26 条回归）。
2. **在线冒烟（scripts/m4_smoke.py）**：2 个库内问题 → 回答含 `[S#]` 且**非法编号 = 0**（引用 100% 可追溯）；2 个超纲问题 → **拒答**（含拒答话术、无编造编号）。
3. **一条命令可用**：`D:\python\python.exe -m vaultmind.ask "问题"` 输出回答 + 引用清单 + 校验结果；`--context-only` 可预览组装质量。
4. **红线零违反**：本模块只读 `data/vaultmind.db` 与检索结果，不写 Vault；默认本地模型、无云端调用；问题文本不外发。

## 3. 红线（叠加通用红线）

- 只读 Vault（同立项书红线 ①）；生成结果**不落盘**（除非用户要求导出）。
- 引用必须来自**本次检索上下文**，生成器提示词强制"资料不足即拒答、严禁编造"。
- 拒答判定是**规则启发式**（正则话术），不引外部模型打分——面试口径："拒答靠提示词约束 + 规则校验双层"。

## 4. 风险预案

| 风险 | 预案 |

| 7B 模型生成慢（decode 限速） | 记录 prefill/decode 实测；上下文预算 6000 字符控制 prefill；不阻塞（M6 有本地 vs 云端成本/延迟对比） |
