# VaultMind 求职收尾清单（用户侧动作 · 按顺序执行）

> 这些动作需要你的账号与人工操作，AI 无法代办。全部就绪 = 项目彻底完成，可交付《面试答辩手册 PDF》配套使用。

## 1. GitHub 发布（~10 分钟）

1. 浏览器打开 github.com 登录 → New repository → 名称 `vaultmind`，**Private 或 Public 自选**（Public 便于投简历展示；内容已过红线打包探针）。
2. 本地推送（在本机任意终端）：
   ```powershell
   cd /d D:\RAG
   git remote add origin https://github.com/<你的用户名>/vaultmind.git
   git push -u origin main
   ```
3. 若本机直连 github.com 超时（已知网络事实），用加速镜像：
   ```powershell
   git push -u origin main   # 失败时改用：
   git push -u https://gh-proxy.com/https://github.com/<你的用户名>/vaultmind.git main
   ```
4. 仓库 README 会自动展示（已含指标表与复现指南）；可选：把 `dist/vaultmind-source-20260916.zip` 作为 Release 附件（无 Vault 内容的干净源码包）。

## 2. 录屏（~3 分钟，建议 Xbox Game Bar：Win+G）

脚本顺序（对应立项书演示素材）：

1. （0:00）打开 `run_api.bat` → 浏览器 `http://127.0.0.1:8000`
2. （0:20）问答页提问「CET-4 项目用了什么去重方案？」→ 展示答案 + 点击 [S#] 引用跳转 Obsidian 原笔记
3. （0:50）再问一个超纲问题（如"今天比特币价格"）→ 展示拒答
4. （1:10）切「分析看板」→ 库规模 / 基线指标达标条 / 坏例账本
5. （1:40）终端跑 `python -m vaultmind.eval` → 指标表复现
6. （2:10）展示 `reports/ablation.md` 六组消融表 + 负结果结论
7. （2:40）收尾一句话：项目定位 + 三条简历 bullet

> 录屏前自检：`ollama serve` 运行中（curl http://127.0.0.1:11434/api/tags）；跑一遍 `scripts/env_check.py` 全 PASS。
